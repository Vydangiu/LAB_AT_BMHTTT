# LAB_AT_BMHTTT

Repository lưu trữ bài thực hành môn **An toàn bảo mật hệ thống thông tin**.

## LAB 1 – Bắt gói tin Telnet - SSH

### Mục tiêu

Thực hành mô phỏng kết nối Client/Server sử dụng **Telnet** và **SSH**, đồng thời sử dụng **Wireshark** để bắt và phân tích các gói tin mạng.

### Môi trường thực hành

- **Windows 11:** PuTTY, Wireshark
- **Ubuntu Server 26.04:** Telnet Server / SSH Server
- **Windows Server 2025:** SSH Server
- **VMware:** Môi trường máy ảo

### Nội dung thực hành

- Cài đặt và cấu hình Telnet Server trên Ubuntu.
- Tạo tài khoản người dùng để đăng nhập Telnet.
- Kết nối từ Windows 11 đến Ubuntu bằng PuTTY.
- Sử dụng Wireshark để bắt các gói tin Telnet.
- Phân tích dữ liệu truyền qua Telnet.
- Cài đặt và cấu hình SSH.
- Kết nối SSH giữa Client và Server.
- Bắt và phân tích gói tin SSH bằng Wireshark.
- So sánh đặc điểm bảo mật giữa Telnet và SSH.

### Công cụ sử dụng

| Công cụ | Mục đích |
|---|---|
| VMware | Tạo và chạy các máy ảo |
| PuTTY | Kết nối Telnet/SSH |
| Wireshark | Bắt và phân tích gói tin |
| Ubuntu Server 26.04 | Telnet/SSH Server |
| Windows 11 | Client và phân tích gói tin |
| Windows Server 2025 | SSH Server |
